# DevOps Platform Lab

Hands-on DevOps & Platform Engineering laboratory focused on enterprise-grade infrastructure, automation, containers, Kubernetes, OpenShift, CI/CD, GitOps, observability, SRE and cloud platform engineering.

## Objectives

- Linux / RHEL administration
- Git and GitHub
- Containers with Podman
- Container image lifecycle
- Ansible automation
- Terraform / Infrastructure as Code
- Kubernetes
- OpenShift
- CI/CD
- GitOps
- Observability
- SRE
- Security
- Networking
- Storage
- Enterprise Platform Engineering

## Lab Architecture

The laboratory runs on a Proxmox-based environment and progressively evolves from a single-node environment to a multi-node platform.
